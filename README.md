## 📦 Données

Les fichiers de données sont trop volumineux pour GitHub.
Téléchargez-les depuis Google Drive :
👉 [[Lien Google Drive](https://drive.google.com/drive/folders/1kybZ8CARsXCaplvh8TxSlL3I-vPcN9Or?usp=sharing)]

Après téléchargement, placez les fichiers dans :

- `data/processed/` → clean_reviews.csv, train.csv, val.csv, test.csv
- `data/vectorized/` → *.pkl

Apres telechargement, placez les fichier dans models/distilbert_finetuned
